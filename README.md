# Frame Goa

Build a modern React + TypeScript + Tailwind web app called FRAME//GOA.

The app is an HH Goa 2026 identity frame generator.

Users can:

• Upload a selfie

• Enter name, handle, college, city and role

• Choose from 4 different HH Goa themed frame designs

• See a live preview

• Download the frame as a PNG

• Share using X (with fallback copy text)

• Use the app without login

The design should feel premium, hacker-inspired, Goa-inspired, responsive and original.

Use React, TypeScript and Tailwind.
