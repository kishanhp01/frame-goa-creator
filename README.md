# ⚡ FRAME//GOA

> **Your identity. Your frame. Your Goa.**

**FRAME//GOA** is a modern identity-frame generator built for **HH Goa 2026**. Create a personalized hacker-house-inspired profile frame using your selfie, identity details, and one of four unique Goa-themed designs.

🌴 **Goa energy × Hacker culture × Personal identity**

---

## ✨ Features

* 📸 **Upload Selfie** — Add your own photo to the frame.
* 🪪 **Personal Identity** — Enter your name, handle, college, city and role.
* 🎨 **4 Frame Designs** — Choose from different HH Goa-inspired visual styles.
* ⚡ **Live Preview** — See your identity frame update instantly.
* 📥 **PNG Export** — Download your final frame as a high-quality PNG.
* 𝕏 **Share on X** — Share your creation directly to X.
* 📋 **Copy Fallback** — Easily copy your sharing text if direct sharing isn't available.
* 🔓 **No Login Required** — Jump straight in and create.
* 📱 **Responsive** — Designed for desktop, tablet and mobile.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* [Node.js](https://nodejs.org/)
* npm
* Git

### Installation

```bash
git clone <your-repository-url>
cd <repository-name>
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local development URL shown in your terminal.
